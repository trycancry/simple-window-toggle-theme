# Introduction
A simple system tray utility that lets you quickly toggle between Windows 11 dark and light themes with a double click. It fully applies theme changes across the taskbar, File Explorer, and system tray icons.

You can also choose what the tray action toggles from the **Toggle target** submenu:

- **Apps only** — toggles the app theme only
- **Windows only** — toggles the Windows system theme only
- **Apps + Windows** — toggles both together

For backward compatibility, **Apps + Windows** remains the default. The selected target is remembered between launches.
